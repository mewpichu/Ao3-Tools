[ hide site ui ]
  1. Copy the CSS below (or download the file).
  2. On AO3, go to Dashboard → Skins → My Site Skins → Create Site Skin.
  3. Give it a name, paste the CSS into the big text field, and hit Submit.
  4. Back on the Skins page, press Use.

Your settings are saved automatically in this browser. Come back and tweak any time.
